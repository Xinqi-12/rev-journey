# Cac lenh GDB don gian
gdb ./hello             : Khoi dong gdb voi file hello
b <ten ham>|<dia chi>   : Dat breakpoint
r <tham so>             : Chay chuong trinh voi tham so
i r                     : Xem toan bo thanh ghi
x/s                     : Xem chuoi string tai dia chi
x/4x                    : Xem 4 byte hex
si                      : Chay 1 lenh 
ni                      : Chay qua 1 lenh (neu call thi chay het func)
c                       : Tiep tuc chuong trinh
q                       : Thoat
